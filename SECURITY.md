# Security

This repository holds small, synthetic, local-only examples, not a security product. Bellows here is a teaching rewrite; it does not make an agent safe to browse on its own. Do not point anything here at real accounts, systems or data. To report a potential vulnerability or a sensitive problem in these files, use GitHub's private vulnerability reporting: open this repository's **Security** tab and choose **Report a vulnerability**. Don't open a public issue for it, and don't post secrets or exploit details anywhere public. If private reporting ever appears unavailable, email hello@robhunterworks.com.
