# The Dunvaric Kingdom: the public shelf

The Dunvaric Kingdom is the system I use to direct sustained work with AI agents across unlike projects: houses with their own authority, crafts they share, and a person who decides. It is private. This repository is its public shelf, organized by the nine shared crafts, and it fills in one craft at a time as each piece is cleaned up and written about.

Most shelves are empty on purpose. An empty shelf says what's coming without pretending it's here.

Every shelf uses the same three labels: **Observed** (it happened, and the record is here), **Built, not exercised** (the code exists and passes its own tests, but hasn't been run against a real system), and **Planned** (written down so it gets done; not done).

## What's here, and what isn't

Everything on this shelf is a small, standalone rewrite of a working piece, with its own tests, using only Python's standard library (Python 3.9 or newer). None of it is the private system itself, and none of it reaches a network, an account or a real target. Each piece says plainly what has been tested and what hasn't.
