# Remembering

> A project can be woken up, oriented and checked for drift, and the day's decisions get captured and saved, so the next session picks up where this one ended.

**Public now:** the [Hearth kit](hearth-kit/), a small, runnable version of the pattern: kindle, capture, fold and bank, with session claims, a filesystem-aware fingerprint and the eight conditions as tests.

Introduced in [*Welcome to the Kingdom*](https://robhunterworks.com/writing/welcome-to-the-kingdom/). Its own essay is [*What It Takes to Remember*](https://robhunterworks.com/writing/what-it-takes-to-remember/).
