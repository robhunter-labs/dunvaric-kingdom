# Defending

> Outside content is treated as data, never as instructions. Anything leaving for the public gets checked for what it might leak.

**Not yet public.** One piece of this craft is already on the shelf: the quarantine half of [Bellows](../03-sensing/bellows/) lands every piece of outside content as untrusted data, fenced so it can't pose as an instruction, and only a named person can promote it.
